byte a = 10;
byte b = 20;

System.out.println(a + b);

Output: 30

⚠️ Remember: byte + byte becomes int

byte + byte=int
short+short=int

byte a = 10;
byte b = 20;

byte c = a + b;
System.out.println(c);

Output: ❌ Compilation Error

Because the result of a + b is int, not byte.
Correct:

byte c = (byte)(a + b);

char c = 'A';

System.out.println(c + 1);

Output: 66

Why? char is promoted to int during arithmetic.


NOTE: byte,short,char are converted into int during expression evalutaion

Output:

54
6

53 + 1 = 54

For Core Java screening tests, pay special attention to:

byte, short, char → int promotion
int → byte overflow
double → int decimal truncation
char → int conversion
int → char casting
Integer division vs floating-point division
Where the cast is placed
Arithmetic expressions involving different data types
Increment/decrement with byte
Compilation errors caused by implicit narrowing
Most important trick to remember
(double)(10 / 4)   // 2.0
(double)10 / 4     // 2.5

The position of the cast matters.
