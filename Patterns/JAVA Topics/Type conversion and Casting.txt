⚠️ Remember: byte + byte becomes int

byte + byte=int
short+short=int

byte a = 10;
byte b = 20;

byte c = a + b;
System.out.println(c);

Output: ❌ Compilation Error

Because the result of a + b is int, not byte.
Correct:

byte c = (byte)(a + b);
